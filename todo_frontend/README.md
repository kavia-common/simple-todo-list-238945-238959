# todo_frontend

React 17 Todo app with a Welcome landing page.

## Routes
- `/` — Welcome page (landing view)
- `/todos` — Todo UI

## Features
- Add / edit / delete todos
- Mark complete/incomplete
- Filter: all / active / completed
- Clear completed
- Persists in browser `localStorage`

## Development

```bash
npm install
npm start
```

The dev server uses `.env` variables already present in this container.
